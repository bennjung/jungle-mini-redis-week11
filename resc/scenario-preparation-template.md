# 테스트 시나리오 초안 검토 메모

이미 작성된 시나리오를 처음부터 다시 만들지 않는다. 대상 문서를 읽고 아래 세 항목 중 필요한 것만 짧게 적어 온다. 의견이 없으면 작성하지 않아도 된다.

첫 검토 대상: [값 보관·조회·폐기](01-storage-scenario.md).

- **빠진 상황:** 어떤 상황을 더 확인해야 하는가?
- **다른 의견:** 어느 항목의 기대 결과가 달라야 한다고 생각하는가? 이유는?
- **미정 사항에 대한 생각:** 문서 끝의 미정 사항 중 어떤 동작이 맞다고 생각하는가? 모르겠으면 질문만 적는다.

예: “같은 키에 다시 저장하는 경우가 빠져 있다. 나는 새 값으로 바뀌어야 한다고 생각한다.” 이는 개인 의견의 예시이며 확정된 동작이 아니다.

모임에서는 기존 초안을 함께 확인하고 위 의견과 미정 사항을 논의한다. 합의한 내용만 대상 문서에 반영하며, 개인 메모를 확정 계약으로 취급하지 않는다. 설계와 코드는 아직 작성하지 않는다.
